# M3 Admission and surges — 1:50–2:20 (30 min)

> References: `DESIGN-REFERENCE.md` is the detailed design (signatures, SQL, parameters, concurrency rules, the twenty design answers); "ARCH › section" is shorthand for it. `ARCHITECTURE.md` is the high-level overview. `ARCH-NOTES.md` items are cited by number.

## Overview

**What this milestone accomplishes.**

- Admission control exists: every incoming event is checked, cheapest first, against a global backlog cap, its tenant's token bucket and its tenant's backlog cap before any key work, so a rejected event costs no KMS call and no data-key message. Ingest now answers rate-limited and backlog-full (429) and overloaded (503) with Retry-After, alongside M2's key-path codes.
- Fair-share shedding: when the whole system is full, only tenants holding more than their share of the backlog are refused, so the light majority is never rejected; the same single backlog read that decides the shed also classes the rejection as within- or over-share, which is what makes the L4 counter falsifiable.
- Delivery-side fairness: the scheduler interleaves within-share and over-share tenants instead of one plain turn per tenant, so a light tenant's single message does not wait behind every heavy tenant's full batch during a global surge (the recommended Scheduler-class decision; the light-turn count is raised from the design's 4 to 32 for stability).
- Surge controls and a scenario runner: a manual endpoint multiplies one tenant's rate or everyone's; the two surge scenarios Ben kept in P0 (D8) are the first scripted scenarios, driven by a phase runner that publishes a card countdown, refuses a second concurrent start and can be stopped; the snapshot gains the L4 within/over-share rejection split.
- What becomes demonstrable, by numbers on the raw stream rather than on a page: L4's hold-and-shed story under a ×10 offered load (delivered throughput stays at capacity, backlog levels off at its cap, within-share rejections zero while over-share rejections flow, a tail tenant accepted throughout), and L2's economy on the surging tenant (rate-limited events never reach the key, so its KMS calls stay flat).
- Deliberately not yet done: no scenario targets, affected set, recovery tail or drain measurement, and no fault scenarios, cards or charts (M4); no L4 light (M5, which judges from the counter built here); retention expiry is compiled but not wired (M5). The expected cut is fair-share shedding, taken only if the ×10 run reaches the global cap yet never shows an overload rejection; the fallback is a plain global cap that rejects everyone above it and also disables the two-class scheduler pass. The Stop handler is the pre-agreed valve if the clock runs short (Start only; Stop in M4).

## Interfaces and types

`internal/admit` is new in M3, so its surface is reproduced from DESIGN-REFERENCE.md › internal/admit with one amendment: `Admit` returns the share class it decided on, from the same `Backlog(idx)` read as the shed decision, so the L4 counter is falsifiable (a reversed comparison or `Total` used for `Backlog` shows up as within-share 503s) and the ack race between "shed" and "classify" cannot exist.

```go
package admit

var (
	ErrRateLimited = errors.New("admit: rate_limited")
	ErrBacklogFull = errors.New("admit: backlog_full")
	ErrOverloaded  = errors.New("admit: overloaded")
)
// Backlog is the ledger view admission needs (queue.Store).
type Backlog interface { Backlog(idx int) int; Total() int; Backlogged() int }
// Clock feeds x/time/rate's AllowN.
type Clock interface { Now() time.Time }
// Config sizes the gate; FairShare=false is the M3 cut line (plain global cap).
type Config struct { Tenants int; Rate float64; Burst, TenantCap, GlobalCap int; FairShare bool; Backlog Backlog; Clock Clock }
// Gate applies global cap, token bucket and tenant cap in the spec's order.
type Gate struct { /* limiters []*rate.Limiter; cfg */ }
func New(cfg Config) *Gate
// Admit returns nil or one sentinel plus the share class of the one Backlog(idx) read it decided on. [amends ARCH: Admit(idx int) error]
func (g *Gate) Admit(idx int) (within bool, err error)
// FairShare is GlobalCap / max(1, Backlogged) when FairShare is on, else math.MaxInt; two atomics, no lock (Next calls it under sched.mu).
func (g *Gate) FairShare() int
// WithinShare reports Backlog(idx) ≤ FairShare() (kept for callers outside Ingest; Ingest uses Admit's value).
func (g *Gate) WithinShare(idx int) bool
```

```go
// Admit, check order of ARCH › Shared types ("global cap → token bucket → tenant backlog cap → key"); a token consumed by a request that then fails is not refunded.
func (g *Gate) Admit(idx int) (within bool, err error) {
	b := g.cfg.Backlog
	bl := b.Backlog(idx)                       // the ONE read; shed decision and L4 class both use it
	within = bl <= g.FairShare()               // FairShare=false ⇒ MaxInt ⇒ always within
	if b.Total() >= g.cfg.GlobalCap && (!g.cfg.FairShare || !within) { return within, ErrOverloaded }   // the cut sheds everyone, classed within (by design)
	if !g.limiters[idx].AllowN(g.cfg.Clock.Now(), 1) { return within, ErrRateLimited }              // rate.NewLimiter(rate.Limit(Rate), Burst) per tenant
	if bl >= g.cfg.TenantCap { return within, ErrBacklogFull }
	return within, nil
}
```
