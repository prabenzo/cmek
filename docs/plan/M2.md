## Overview

**What this milestone accomplishes.**

- The key lease becomes real. Until now every cached data key was usable forever; from here a tenant's cached keys are usable only inside a 30 s lease on its key authorization, renewed lazily by traffic or backlog once the lease is 15 s old, measured from the moment the renewal was sent rather than answered, and expiring 1 s early locally. When the lease lapses, the tenant's plaintext keys are purged.
- Down is told apart from revoked. Every KMS answer is classified once (OK, transient, authoritative deny, poison) and drives the spec's four-state tenant key machine: a timeout or outage rides through until the lease lapses and then fails closed; a deny purges the tenant's keys at once and parks it, with a re-probe every 5 s to catch a re-grant.
- One component talks to the KMS. The key fetcher applies a 500 ms per-call deadline, coalesces fetches for the same key, caps calls in flight per provider (32) and, unless cut, per tenant (2), and backs off per tenant with jitter (0.5 s doubling to 8 s, one probe at a time); every call and purge is audited.
- Tenant parking. The scheduler dispatches only tenants whose key is hot, workers never call a KMS, and a message whose key has gone between encrypt and decrypt is released untouched with its retry budget intact (S4); nothing is decrypted past the revocation bound (S3).
- The fake KMS gains fault injection per provider or per tenant (fast-fail, error rate, lognormal latency), revoke and restore with a ground-truth log of key events, and two manual endpoints (faults, revoke/restore) that the later scenarios script.
- Demonstrable in the raw counters, before any page exists: a gcp fast-fail (the band turns yellow then orange, the other two providers untouched, all green within about 12 s of clearing, parked messages delivered) and a single-tenant revoke (purple within 30 s, a 403 key-revoked answer at ingest, ACTIVE again within 5 s of restore): the S3 bound, the S4 ride-through and L3 self-healing as numbers. Unit tests cover the classifier, the lease and the envelope, plus one scripted walk through every state transition, green with the race detector on.
- Deliberately not yet done: the per-tenant in-flight cap is the expected cut (the per-provider cap stays); the slow-KMS observation and its in-flight tile go to M4, six extra test rows go to M5, and there is no admission control, no page and no checker yet.

// Classify maps a call result to its class: nil → OK; ErrPoison → Poison; context deadline/cancel and kms Timeout/Unavailable → Transient; AccessDenied/KeyDisabled → Deny; unknown → Transient.
func Classify(err error) Class

// Lease is the window in which cached DEKs may be used; the zero value is "no lease".
type Lease struct { SentAt time.Time; TTL, SoftTTL, Early time.Duration }
// Renew moves SentAt forward only; returns false when sentAt is not later than SentAt.
func (l *Lease) Renew(sentAt time.Time) bool
// Usable reports SentAt != 0 && now < SentAt + TTL − Early (29 s of use from the send instant).
func (l Lease) Usable(now time.Time) bool
// SoftDue reports now ≥ SentAt + SoftTTL.
func (l Lease) SoftDue(now time.Time) bool
// Remaining returns SentAt + TTL − Early − now (≤ 0 when lapsed).
func (l Lease) Remaining(now time.Time) time.Duration
// Backoff returns min(min×2^(n−1), max) × (1 + jitter × (2u − 1)) for attempt n ≥ 1 and u ∈ [0,1).
func Backoff(n int, min, max time.Duration, jitter, u float64) time.Duration

// Info returns the tenant read model (M2: only State, LeaseAge, LeaseRemaining filled; the rest in M4).

// dek is one DEK: wrapped bytes forever, plaintext only while hot. key == nil means cold.
type dek struct { id string; wrapped []byte; kekVersion int; key *[32]byte; msgs int; createdAt, hotSince time.Time }
// tenant is everything m.mu protects for one tenant.
type tenant struct {
	idx int; spec TenantSpec; seq int                 // seq → next DEK id "<tenant>/<seq>"
	state State; lease Lease
	deks map[string]*dek; active *dek
	attempt int; nextProbeAt, deniedAt time.Time; probing bool
	pending map[string]time.Time                     // dekID → dueAt (worker asked for a cold DEK) [SC-F5]
	waiters, inflight int                            // IngestWaiters cap; TenantInflight cap (0 = none)
}
// purge zeroes and drops every plaintext, clears pending, keeps wrapped bytes; returns how many were hot.
func (t *tenant) purge() int

// result is one KMS outcome as apply consumes it.
type result struct { sentAt time.Time; class Class; err error; key [32]byte; dk kms.DataKey; latency time.Duration }
var errBusy = errors.New("cmek: tenant inflight cap") // unclassified; never audited; ARCH addendum: the M5 no-globals grep must be `grep -vi err` (this name has no capital Err; `var (` blocks need the same care)
// call is the only function that touches kms.KMS: tenant cap → provider semaphore raced against a KMSTimeout context → sentAt → Unwrap|GenerateDataKey → release → return. It runs with m.mu released and EMITS NO AUDIT (see apply).
func (m *Manager) call(t *tenant, op string, d *dek) result
// probe unwraps t.active or generates when t.active == nil (singleflight "<t>/active" | "<t>/generate"), then apply. [SC-F2]
func (m *Manager) probe(t *tenant)
// warm unwraps one non-active DEK (singleflight "<t>/<dekID>"), then apply.
func (m *Manager) warm(t *tenant, d *dek)
// generate allocates "<t>/<seq+1>" under m.mu, calls GenerateDataKey, PutDEKs the wrapped form BEFORE apply. A PutDEK error is NOT a KMS outcome: no state change, no audit, no backoff (like errBusy); generate returns the store error unclassified, the cold-path caller returns it to Ingest (→ 500 internal via world.Outcome; counted, must stay 0) and a Tick-spawned probe simply retries next sweep.
func (m *Manager) generate(t *tenant) (*dek, result)
// apply is the only state mutator, always under m.mu; rows OK / Transient / Deny / errBusy exactly as ARCH › (c) apply table; writes m.states[idx]; clears probing for probe and warm. It emits the audit lines: first the unwrap/generate line (op, outcome, class, latency), then a state line if the state changed. So Auditor.Audit is always called under m.mu (ARCH lock table, literally), the order is deterministic (PutDEK → apply → audits), and errBusy/store errors produce no line.
func (m *Manager) apply(t *tenant, op string, d *dek, r result)
// backoff wraps Backoff with cfg values and cfg.Jitter.Float64().
func (m *Manager) backoff(n int) time.Duration
