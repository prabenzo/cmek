`scripts/m0-ticker-check.sh` (usage: `URL [A|B|AB]`, default `AB`):

```bash
#!/usr/bin/env bash
set -u; URL=${1:?usage: $0 URL [A|B|AB]}; PART=${2:-AB}
hz() { curl -sf "$URL/health" || { echo "FAIL: /health not 200 (check --allow-unauthenticated)"; return 1; }; }
field() { grep -oE "\"$1\":[^,}]+" | cut -d: -f2 | tr -d '"'; }
hz >/dev/null || exit 1   # absorbs the cold start
if [[ $PART == *A* ]]; then echo "A: streaming 60 s"
  curl -sN --max-time 62 "$URL/v1/stream" | perl -MTime::HiRes=time -ne '
    next unless /"tick":(\d+)/; $t=$1; $now=time;
    if (defined $prev) { $g=$now-$prev; $max=$g if $g>$max;
      if ($g>1.5) { $over++; printf "A: gap %.2fs tick_delta=%d (%s)\n", $g, $t-$pt, ($t-$pt)>$g ? "buffering" : "starved" } }
    $prev=$now; $pt=$t; $first//=$t; $last=$t; $n++;
    END { printf "A: frames=%d ticks_advanced=%d max_gap_s=%.2f gaps_over_1.5s=%d\n", $n, ($last//0)-($first//0), $max//0, $over//0 }'
fi
if [[ $PART == *B* ]]; then
  for i in $(seq 10); do H=$(hz) || exit 1; [[ $(echo "$H" | field viewers) == 0 ]] && break; sleep 1; done
  T1=$(echo "$H" | field ticks); W1=$(echo "$H" | field world)
  [[ $T1 =~ ^[0-9]+$ ]] || { echo "FAIL: health unparsable: $H"; exit 1; }
  echo "B: idle 30 s (viewers=$(echo "$H" | field viewers))"; sleep 30
  H=$(hz) || exit 1; T2=$(echo "$H" | field ticks); W2=$(echo "$H" | field world)
  echo "B: idle_ticks=$((T2-T1)) world=$W1->$W2 viewers=$(echo "$H" | field viewers)"
fi
```

Verdicts. Two independent signals; only `ticks_advanced` decides D9.

| Signal | PASS | Rerun once | Act |
| --- | --- | --- | --- |
| A ticks (CPU while a stream is open) | `ticks_advanced ≥ 100` (≥ 1.67/s of 2/s) | `60 ≤ ticks_advanced < 100` → rerun A once (`… A`) | `< 60` on the first run, or `< 100` on the rerun → D9 fallback now |
| A gaps (buffering, never a billing change) | `gaps_over_1.5s ≤ 2` | — | `≥ 3` with ticks ≥ 100: frames are batched (each gap line says `buffering` when the tick delta spans the gap; `starved` means the ticker itself stalled, which the ticks row already caught). Check Flush after every frame, no gzip, `WriteTimeout: 0`; retry from another network (ARCH › Answers › Q20, SC-F11) |
| B (throttled when idle) | `idle_ticks ≤ 20` | `20 < idle_ticks < 50`, `world` changed (instance replaced), or `viewers ≠ 0` at T1 (stream not yet torn down) → rerun `… B` | `≥ 50` with `world` unchanged and viewers 0: CPU is allocated while idle → `gcloud run services describe killswitch --region $REGION` and confirm `--cpu-throttling` took; a cost note, not a D9 decision |

D9 fallback: `gcloud run services update killswitch --region $REGION --no-cpu-throttling --min-instances 1` (1–2 min, new revision), then `… A` must PASS (B will then read ≈ 60, the expected shape under instance-based billing); write "D9 fallback taken" in TIMELOG and later in README. A PASS keeps request-based billing and the pause-at-0-viewers design (ARCH › World › Lifecycle).

## Risks specific to this milestone

- **Long poles are the builder image pull and the first `gcloud run deploy`** (1–2 min, unavoidable), not the compile (< 1 min native). Mitigation: `docker pull golang:1.26` at 0:00 while gcloud is configured; `go mod download` in its own layer; the 0:10 abort trigger; the "not live by 0:20" rule.
- **SSE frames buffered** (Cloud Run front end, a proxy, our server). Mitigation: headers, Flush and `WriteTimeout: 0` per ARCH › Q20 / SC-F11; the local 3-second curl proves streaming before deploy; the gap row and its `buffering`/`starved` tag separate batching from starvation, so a proxy hiccup never flips billing.
- **`--allow-unauthenticated` blocked by an org policy** (deploy warns, URL returns 403). Mitigation: the script's first line; if 403, `gcloud run services add-iam-policy-binding killswitch --region $REGION --member=allUsers --role=roles/run.invoker`; if the policy forbids it, deploy to a personal project.
- **False verdicts from cold start, instance replacement or a stream not yet torn down when B starts.** Mitigation: the script warms `/health`, polls until `viewers == 0` before T1, compares `world` ids and prints `viewers`; the Rerun column.
- **Two writers on one repo.** Mitigation: Claude pushes at 0:07 and 0:12 only; Ben touches only `web/uplot*` and `docs/TIMELOG.md` and commits once at 0:19; Claude `git pull --rebase` before the first M1 commit.
- **Session limits (facts, ARCH-NOTES 2).** No Docker daemon and jsdelivr 403: the image and uPlot are Ben's; Claude's Dockerfile check is the builder's exact `go build` line. Session `go` commands need the module proxy for the 1.26 toolchain.
- **`toolchain` line in go.mod.** Tidy under a newer laptop toolchain may add `toolchain go1.2x.y`; the step-1 grep catches it; under the image's `GOTOOLCHAIN=local` a newer line fails the build rather than downloading.
