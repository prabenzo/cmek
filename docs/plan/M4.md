```go
package metrics

// SetTargets replaces the affected set and freezes the baseline (mean of the last BaselineTicks windowed healthy p99s); only scenarios call it. ClearTargets ends the affected set.
func (r *Registry) SetTargets(idx []int)
func (r *Registry) ClearTargets()
// Affected reports the tenant's affected bit (lock-free atomic load); world.Tenant reads it.
func (r *Registry) Affected(idx int) bool
// SetScenario (M3) publishes the card countdown; a zero endsAt means an open-ended phase (ends_at null). SetCleared marks the fault-cleared instant from which recovery_s and drain_s are measured.
func (r *Registry) SetCleared(at time.Time)
// Recovered reports whether every target is ACTIVE and the affected backlog sum is ≤ Config.DrainSlack (= Workers × ClaimBatch, one rule from Params; M3 hand-off 3 amends ARCH's "0" [SF-F13]: Backlog counts claimed rows and the top-150 carry ≈ 3.4 rows in flight at baseline) since SetCleared (tail end) and the two durations.
func (r *Registry) Recovered() (recovered, drained time.Duration, done bool)
// InflightSource reports KMS calls inside a provider (cmek.Manager.Inflight); Config.Inflight, read in tick step 2 before reg.mu, feeds the snapshot inflight{} and the #inflight tile.
type InflightSource interface { Inflight(provider string) int }
// Timeline appends one free-text line with the next seq (scenario markers, the restored line; the checker in M5).
func (r *Registry) Timeline(text string)
// TenantAudit returns the last n ring entries for one tenant, newest first; TenantCallsPerMin counts unwrap/generate entries newer than 60 s (a lower bound when the ring covers less).
func (r *Registry) TenantAudit(idx, n int) []Audit
func (r *Registry) TenantCallsPerMin(idx int) float64
```

Unexported contract for `hist.go` (Q9), the only new math in the milestone:

```go
// hist is one tick's latency histogram: bucket b covers [1ms·1.5^b, 1ms·1.5^(b+1)); b = 27 is the 60 s cap.
type hist [28]atomic.Uint32
// bucket maps a latency to its index: clamp(floor(log(d/1ms)/ln15), 0, 27); ln15 is a Registry field set in New (no package-level var: CI greps '^var ').
func (r *Registry) bucket(d time.Duration) int
// p99 sums the last P99Window ticks for one class (n samples; 0 when n == 0), takes rank = floor(0.99·n)+1 (the first sample of the slowest 1 %; n=100 → the 100th), finds the first bucket whose cumulative count ≥ rank, and returns lo + (hi−lo)·(rank − cumBefore)/inBucket (linear interpolation inside the bucket; Decisions).
func (r *Registry) p99(class int) time.Duration
```

Registry fields added: `affected []atomic.Bool` (read lock-free by `Delivered`/`Ingest` at record time, Q8), `p99Ring []time.Duration // len BaselineTicks, made in New; stores the windowed healthy p99 exactly as the snapshot reports it each tick`, `baseline time.Duration`, `targets []int`, `scen struct{ name, phase string; endsAt, clearedAt, recoveredAt, drainedAt time.Time }`, `trans map[[3]uint8]int` (provider, from, to → count this tick; provider(idx) = `Providers[idx*len(Providers)/len(Tenants)]`), `ln15 float64`. Tick changes (ARCH › (f)): **step 2**, before `reg.mu`, reads states, `Total()`, Σ `Backlog(idx)` over the current targets and `Inflight(p)` for each of `Providers` into locals; **step 5** uses only those locals: `recoveredAt` on the first tick at which every target is `Active`, `drainedAt` when the affected sum is ≤ `DrainSlack` (+2), both only after `clearedAt`; **step 6** (aggregation rule, so nobody invents one): transitions between ACTIVE and RIDING_THROUGH are never single lines — they are buffered per provider and flushed once per second as `azure: 5 ACTIVE → RIDING_THROUGH, 4 back` (the slow-KMS trickle is ≈ 5 singles/s × 60 s = 300 lines, more than the 200 ring, and even per-tick lines would be 240); every other `(prov, from, to)` with count ≥ `AggregateMin` in a tick becomes `12 gcp tenants RIDING_THROUGH → KEY_UNAVAILABLE`, singles keep the M2 form; a REVOKED transition is never aggregated (it carries `N DEKs purged`).

World (ARCH › internal/world; `TenantDetail` verbatim there):

```go
package world

// phase is one timed step; dur 0 means open-ended: it ends on the run's signal (Restore) or Stop.
type phase struct { name string; dur time.Duration; enter func() }
// scenario is a scripted fault or surge; targets is evaluated at Start and handed to metrics.SetTargets (Q8, Q19).
type scenario struct { name string; targets func() []int; phases []phase; exit func() }
// band returns the grid indexes of one provider's contiguous third (aws 0–333, gcp 334–666, azure 667–999).
func (w *World) band(provider string) []int
// tail runs after a normal end: SetCleared(now); every SnapshotInterval poll metrics.Recovered(); end at ≥ ScenarioTailMin once done, or at ScenarioTailMax; post "<scope> restored: N tenants ACTIVE in x s, backlog drained in y s"; ClearTargets; SetScenario("", "", zero). [SF-F7][SF-F13]
func (w *World) tail(ctx context.Context, s *scenario)
```

Runner delta on M3's `run` (+5): `var t <-chan time.Time; var sig <-chan struct{}; if p.dur > 0 { t = w.clock.After(p.dur) } else { sig = s.signal }; select { case <-t: case <-sig: case <-ctx.Done(): … }` (a nil channel blocks, so a timed phase ignores the signal and an open phase never fires at once). **Stop/cancel path**: `exit()` once, `SetScenario("", "", zero)`, `ClearTargets()` — no tail, no restored line (Q19: "cancels the goroutine and runs exit"). `StartScenario` order: 409 check → `s.signal = make(chan struct{}, 1)` (per run, so a stale Restore token cannot end the next run) → `metrics.SetTargets(s.targets())` (freezes the baseline) → `metrics.SetScenario(name, phases[0].name, endsAt)` (zero for `dur 0`) → `metrics.Timeline("scenario provider_outage started: gcp fast-fail for 60 s")` → `go run`. `SetKey(id, "restore")` does a non-blocking send on the running run's `signal` only when that run is `key_revocation` and its target is `id`; `exit` restores again (idempotent). Scenario → API mapping is ARCH › Q19 verbatim (flat `FaultRequest`; `SetKey(byRank[RevokeTenantRank])`; `Surge(byRank[5], 100)`; `Surge("", 5)`; targets gcp band / one tenant / azure band / one tenant / top 150).
