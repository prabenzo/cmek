# Notes and corrections that override DESIGN-REFERENCE.md where they conflict

DESIGN-REFERENCE.md is canonical for package layout, signatures, SQL, concurrency rules, line budgets and the milestone→package table. These notes take precedence on the points below.

1. **Cloud Run deploy command (M0).** Use exactly:
   `gcloud run deploy killswitch --image "$IMG" --region "$REGION" --platform managed --allow-unauthenticated --min-instances 0 --max-instances 1 --cpu-boost --cpu-throttling --timeout 3600 --memory 1Gi --port 8080`
   `--cpu-throttling` is the default and means request-based billing (CPU only while a request is in flight); the D9 fallback is `--no-cpu-throttling` (instance-based billing) plus `--min-instances 1`. `--allow-unauthenticated` is required for a public reviewer URL. The image is pushed to Artifact Registry (`$REGION-docker.pkg.dev/$PROJECT/killswitch/killswitch:<git-sha>`); Ben creates the repository once (`gcloud artifacts repositories create killswitch --repository-format docker --location $REGION`) and runs `gcloud auth configure-docker $REGION-docker.pkg.dev` once. Streaming responses (SSE) are supported by Cloud Run; no special flag.
