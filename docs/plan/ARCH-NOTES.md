# Notes and corrections that override DESIGN-REFERENCE.md where they conflict

DESIGN-REFERENCE.md is canonical for package layout, signatures, SQL, concurrency rules, line budgets and the milestone→package table. These notes take precedence on the points below.

1. **Cloud Run deploy command (M0).** Use exactly:
   `gcloud run deploy killswitch --image "$IMG" --region "$REGION" --platform managed --allow-unauthenticated --min-instances 1 --max-instances 1 --cpu-boost --no-cpu-throttling --timeout 3600 --memory 1Gi --port 8080`
   **Decided 2026-09-22 (Ben): the D9 fallback is taken.** Deploy with `--min-instances 1 --no-cpu-throttling` (one always-on instance, instance-based billing) instead of `--min-instances 0 --cpu-throttling`; the rest of the command is unchanged. Reason: with request-based billing the idle-throttling check could not be made honest, because Cloud Run's front end kept streams open after clients left and the viewer count never returned to zero (see item 11). Consequence: idle time costs money; the World still pauses its traffic when the viewer count is zero and rebuilds after 10 s idle, as designed. `--allow-unauthenticated` is required for a public reviewer URL. The image is pushed to Artifact Registry (`$REGION-docker.pkg.dev/$PROJECT/killswitch/killswitch:<git-sha>`); Ben creates the repository once (`gcloud artifacts repositories create killswitch --repository-format docker --location $REGION`) and runs `gcloud auth configure-docker $REGION-docker.pkg.dev` once. Streaming responses (SSE) are supported by Cloud Run; no special flag.
